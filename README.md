# CatClauded — котики для Claude Code

Каждая открытая сессия Claude Code — кот на лежанке поверх всех окон: спит, работает, потягивается (закончил)
или просит. Когда Claude просит разрешения, кот прыгает на монитор с активным окном, и над ним облачко
«Claude Code просит разрешения · Терминал · Linux» с кнопками **Разрешить**, **Заблокировать**, **Всегда**
(если Claude сам предложил правило) и **Напомнить позже** (5 мин, 15 мин, 1 ч).

Работает на Windows и Linux (X11). Значок на коте показывает, откуда сессия: «▣» десктоп, «›_» терминал, 🐧 Linux/WSL.

## Установка

**Windows.** Распакуйте `CatClauded-<версия>-win-x64.zip` в любую папку и запустите `CatClauded.exe`.
Иконка с котом появится в трее. Чтобы запускать при входе, положите ярлык в `shell:startup`.

**Linux (x64).**

```bash
tar -xzf CatClauded-0.1.3-linux-x64.tar.gz
```

```bash
./CatClauded-0.1.3/CatClauded &
```

Нужны X11 с композитором (для прозрачности) и трей с поддержкой StatusNotifierItem (KDE, Xfce, Cinnamon;
в GNOME — расширение AppIndicator). Для «Открыть окно» и прыжка на монитор с активным окном нужен `xdotool`
(или `wmctrl` — только для «Открыть окно»). В Wayland окна других программ поднять нельзя.

## Подключение к Claude Code

Меню иконки в трее → **Подключить к Claude Code**. Программа покажет, что изменит, и после подтверждения
допишет свои хуки в `~/.claude/settings.json` (или `$CLAUDE_CONFIG_DIR/settings.json`):

- перед первой правкой — копия `settings.json.mwa-backup`;
- ваши настройки и чужие хуки остаются; свои хуки CatClauded узнаёт по заголовку `X-CatClauded-Token`,
  повторное подключение их заменяет, **Отключить** убирает только их;
- на Windows это HTTP-хуки на `127.0.0.1:47322`, на Linux — команды `curl … || true`,
  которые молчат, когда CatClauded закрыт.

Хуки работают в новых сессиях Claude Code: уже открытые перезапустите.

Пока кот ждёт кнопку (до 55 минут), Claude ждёт ответа хука. Ответили в самом Claude — кот уходит.
Если коты или прыжки выключены, либо сессии этого вида скрыты в настройках, хук отвечает сразу и решает сам Claude.

### CatClauded и MyWorkAssist

CatClauded — самостоятельная программа: MyWorkAssist для неё не нужен. Если стоят обе, они живут рядом:
у CatClauded порт 47322 и маркер `X-CatClauded-Token`, у MyWorkAssist — 47321 и `X-MWA-Token`.
Подключение и отключение CatClauded хуки MyWorkAssist не трогают.

Если к Claude Code подключены обе программы, у каждой сессии будет по коту в каждой из них
(и оба будут ждать кнопку). **Рекомендуем подключать одну.**

Сессии агентов самого MyWorkAssist (запущены с `MWA_AGENT=1`) CatClauded не показывает:
хук передаёт эту переменную заголовком `X-CatClauded-Agent`, и такой запрос сразу получает пустой ответ.

### WSL

Настройки → **Команда для WSL — в буфер**. Вставьте её в терминал WSL (нужен `python3`). Хуки в WSL
шлют события через `curl.exe` Windows прямо на `127.0.0.1:47322` этого компьютера.

### Удалённый Linux по SSH

CatClauded работает на вашем компьютере, Claude Code — на сервере. Подключайтесь с обратным туннелем:

```bash
ssh -R 47322:127.0.0.1:47322 host
```

На сервере один раз выполните команду из Настройки → **Команда для Linux по SSH — в буфер**
(нужны `python3` и `curl`). Пока туннеля нет, хуки молчат, и Claude спрашивает как обычно.

## Настройки

Иконка в трее → **Настройки**. Файл: `%APPDATA%\CatClauded\settings.json` на Windows,
`~/.config/catclauded/settings.json` на Linux. Там же журнал `catclauded.log`.

- каких сессий показывать котов: Десктоп · Windows, Терминал · Windows, WSL, Linux;
- прыжки к активному окну, «звать, когда Claude ждёт ответа», звук, размер котов;
- порт (по умолчанию **47322**: 47321 занят MyWorkAssist, обе программы работают одновременно).
  После смены порта нажмите «Подключить» ещё раз и обновите команды в WSL и на серверах.

Щелчок по коту (или «Открыть сессию» в облачке) открывает его сессию: сессию десктопа Claude — прямо в десктопе
(ссылкой `claude://code/continue`), терминал — поднимает его окно. Для этого хуки должны быть подключены версией 0.1.1
или новее: если хуки устарели, CatClauded при запуске сам предложит их обновить. Уже открытые сессии Claude получат новые хуки после перезапуска.

Лежанку и котов можно перетаскивать мышью; место лежанки запоминается. Несколько просящих стоят очередью:
колесо мыши меняет переднего, переднего тащат вместе с очередью, заднего можно вытащить отдельно.

## Сборка

Нужен .NET 9 SDK.

```bash
dotnet test tests/CatClauded.Tests
```

```bash
pwsh scripts/release.ps1
```

Скрипт собирает self-contained single-file для `win-x64` и `linux-x64` в `release/<версия>/` и архивы
`.zip` и `.tar.gz`.

Проверить хуки, не трогая свой `~/.claude/settings.json`:

```bash
CatClauded.exe --print-hooks > hooks.json
```

```bash
claude -p --permission-mode default --settings hooks.json "echo test > t.txt"
```
